Matrix Multiplication Rule

To multiply two matrices, the number of columns in the first matrix must equal the number of rows in the second matrix.

Each entry in the result is found by multiplying a row from the first matrix by a column from the second matrix, then adding the products together.

Simple rule: matrix multiplication works by row × column, not by multiplying matching positions directly.

Quick Example

Here is a simple 2x2 example that shows how row-by-column multiplication works:

A = [1 2; 3 4] and B = [5 6; 7 8]

Top-left entry: (1×5) + (2×7) = 19

Top-right entry: (1×6) + (2×8) = 22

The same row-by-column process is repeated for the remaining entries.

Frequently Asked Questions

What is the rule for matrix multiplication?

You can multiply two matrices only when the number of columns in the first matrix equals the number of rows in the second matrix. Each result entry is found by row-by-column multiplication.

When can you multiply matrices?

Matrix multiplication is possible only when the inner dimensions match. For example, a 2×3 matrix can multiply a 3×4 matrix.

Why is matrix multiplication not commutative?

Matrix multiplication is not commutative because changing the order changes how rows and columns interact, so AB and BA usually produce different results.
